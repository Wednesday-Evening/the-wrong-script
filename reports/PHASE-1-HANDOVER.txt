7. BUGS, LIMITATIONS AND COMPROMISES
===============================================================================

NOT PLAYED END-TO-END THIS PHASE.
  I did not script a full three-route playthrough to each ending. Integrity
  rests on the byte-level diff (one added line), the source counts, and
  reaching the casting scene in a real browser.

SAVE ROUND-TRIP NOT EXERCISED IN-BROWSER.
  Managed browser steps cannot seed localStorage, so I could not watch
  "save -> reload -> CONTINUE". The Lobby's CONTINUE strip is therefore unseen
  in a browser; correctness rests on the key and film code being unchanged and
  the origin being identical.

FILM ROUTES AREN'T URL-ADDRESSABLE (no hash routing) - pre-existing behaviour,
deliberately not changed in this phase.

CARD GLYPHS ARE EMOJI, so they render differently per platform; there is no
real artwork, consistent with the film's convention.

NO SCREEN-READER AUDIT.
  Semantics (aria-current, aria-expanded, aria-live on the continue slot,
  aria-hidden on decorative glyphs, a skip link) are in place but untested with
  assistive tech.

README PREVIOUSLY SAID GitHub Pages should deploy from `main`, which would not
have published anything here; it now says the branch that holds the files
(appjet).

===============================================================================
8. TECHNICAL DECISIONS THAT AFFECT LATER PHASES
===============================================================================

ONE FOLDER PER EXPERIENCE (film/ now; stories/ next). Adding a destination
means creating a folder, giving its card a real href, dropping the Soon badge -
no Lobby restructuring.

CSS/JS LIVE IN assets/, so a new destination can reuse or extend without
touching the film.

THE SAVE CONTRACT IS LOAD-BEARING: key "tws" on this origin must not change, or
players lose progress. Recorded for future phases.

NO BUILD STEP - the site is deployable to any static host exactly as committed.

lobby.js READS BUT NEVER WRITES the save, establishing the pattern for future
"resume" surfaces.
