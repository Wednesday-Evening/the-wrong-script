11. DEFECT REGISTER - APPLICATION FINDINGS (NOT FIXED; THIS PHASE MAY NOT FIX)
--------------------------------------------------------------------------------

No application defect was found that breaks navigation, rendering, storage,
history behaviour or the film. Three observations were recorded. None was
corrected, because this authorisation is verification-only.

  DEF-01  Lobby card meta links are 13px tall
          Route:      /
          Viewport:   390 x 844
          Measured:   a[href="stories/"] "Open now - one story on the shelf"
                      252 x 13 CSS px. Six sibling links of the same kind
                      ("Open now - one game in the cabinet", gallery, social
                      room, archive, creator studio) measure 255 x 23, and
                      "Read it" measures 49 x 16.
          Standard:   WCAG 2.2 SC 2.5.8 asks for 24 x 24 CSS px, with an
                      exception for targets inside a sentence or block of text
                      and a spacing exception.
          Assessment: these are block-level lines inside card meta rows, not
                      links inside a sentence, so the inline exception does not
                      clearly apply. The spacing exception probably does, since
                      the links sit on separate card rows and are 252px wide,
                      but that is a judgement, not a measurement I can certify.
          Impact:     LOW. Each link is wide and easy to hit horizontally, and
                      the same destination is also reachable from the main
                      navigation at 44px. This is a comfort issue for precise
                      touch, not a blocked path.
          Suggested fix (NOT APPLIED): give the card meta links a vertical
                      padding that brings the hit area to 24px or more, or
                      promote them to the 44px pattern used by the card
                      buttons. Requires owner approval and its own pass.

  DEF-02  /film/ has no heading structure
          Route:      /film/
          Measured:   0 h1-h6 elements, 0 footer landmarks, 1 main, 1 nav.
          Assessment: the original production is a standalone full-screen
                      experience and was deliberately preserved as-is in every
                      phase since Phase 1. It has never had headings, and this
                      report does not treat that as a regression - it is
                      pre-existing and protected by the preservation rules.
          Impact:     A screen-reader user gets no heading outline on that
                      route. Whether to add a visually hidden h1 is an owner
                      decision, because it touches the protected film file.
          Suggested fix (NOT APPLIED): a visually hidden h1 plus an outline of
                      the stage, in a separate authorised pass.

  DEF-03  One 41px control on four rooms
          Routes:     /gallery/, /archive/, /creator-studio/, /social-room/
          Viewport:   390 x 844
          Measured:   one standalone control at 41px on each of those routes
                      (1 of 27, 1 of 43, 1 of 22 and 1 of 35 respectively).
          Standard:   clears the 24 x 24 minimum; misses the project's own
                      44px aim by 3px.
          Impact:     LOW. Comfort, not access.
          Suggested fix (NOT APPLIED): confirm which control and adjust its
                      padding if the owner wants the 44px aim met exactly.

12. HARNESS DEFECTS AND HISTORICAL FAILURES (PRESERVED, NOT HIDDEN)
--------------------------------------------------------------------------------

The first accessibility run reported 52 passed, 11 failed. Ten of those failures
were defects in my harness, not in the application. They are recorded here so
the audit trail is complete.

  H-1  Array compared to a number
       The touch-target assertion compared an array of offending elements to 0
       with ===, which is always false. Every route therefore "failed" the
       check, including /film/ whose detail line read "smallest 44px of 5
       targets" - an obvious contradiction.
       Resolution: compare array length; classify inline prose links
       separately. Re-run: the false failures disappeared and one genuine
       finding (DEF-01) remained.

  H-2  Wrong film control clicked
       The film probe clicked the first button in the stage, which is the
       "Sound: off" toggle, so it correctly observed that neither scene text nor
       the save changed, and reported a failure that said nothing about the
       film.
       Resolution: drive the "SKIP INTRO" control instead. Re-run: stage text
       advanced from 45 to 417 characters with no errors.

  H-3  Inline classification differed between two scripts
       The matrix classified "Open now - ..." as inline prose; the probe showed
       it is inside a paragraph but block-displayed, so the accessibility
       harness counted it as a standalone target. The stricter reading was kept,
       because it is the more useful one for touch users, and DEF-01 records the
       measurement either way.

  Historical failures from earlier phases remain in their own reports and were
  not rewritten: reports/PHASE-2-HANDOVER.txt, PHASE-3-HANDOVER.txt,
  PHASE-4-HANDOVER.txt, PHASE-5-HANDOVER.txt, PHASE-6-VERIFICATION.txt (F1, F2,
  F3) and PHASE-7-CREATOR-STUDIO-HANDOVER.txt (section 6.6).
