7. WHAT EACH REFERENCE IMAGE ACTUALLY IS
--------------------------------------------------------------------------------

The pack's own README-USAGE.txt states that these are concept and reference
images, that the boards contain multiple scenes in a single image, and that they
must not be treated as finished room backgrounds. Each image was inspected to
classify it accurately rather than trusting filenames alone.

  01  MULTI-PANEL BOARD + INTERFACE MOCKUP
      12 panels in one image. A floating pill-shaped media controller is shown
      at the top centre (waveform, title, pause, volume slider, expand icon).
      Baked-in labels appear under panels (for example LOBBY, STORIES, ARCADE,
      GALLERY, SOCIAL ROOM) plus a title treatment. It is a design reference for
      a room hub with the controller in place, not a usable background.

  02  MULTI-PANEL COLLAGE BOARD
      12 panels in a 4 x 3 grid of room and environment concepts. The only
      baked-in text observed is the word "ARCHIVE" in one panel. Concept art for
      room atmosphere, not eleven separate background files.

  03  INTERFACE MOCKUP (menu screen over background art)
      Illustrative UI is baked into the image: the title, a "Playing" status
      strip, a navigation bar (HOME, STORIES, GAMES, GALLERY, SETTINGS), a
      tagline and "Enter the Lobby" button, a pull quote, "Online | v1.0.0", and
      Sound/Video toggles. This is a mood reference for interface character.
      Its labels, navigation, claims and controls must not be reproduced in the
      product, as the pack README explicitly requires.

  04  SINGLE ENVIRONMENT ARTWORK
      One cosmic portal plaza scene: reflective floor, lounge with armillary
      sphere, lanterns, archway and staircase into a swirling portal, floating
      islands and a starry sky. No text or UI baked in.

  05  SINGLE ENVIRONMENT ARTWORK
      One cosmic terrace scene with a lone figure, floating island castles,
      waterfalls, galaxy and moon. No text or UI baked in.

  06  SINGLE ENVIRONMENT ARTWORK
      One night cosmic scene: portal at the top of a stone staircase, runic
      floor, crystals, glowing tree, castle on a floating island. No text or UI
      baked in.

  07  SINGLE ENVIRONMENT ARTWORK
      One portal scene with archway vortex, runic plaza, armillary sphere,
      castle and floating islands. No readable text; markings are geometric
      symbols.

  08  MULTI-PANEL COLLAGE BOARD
      12 panels: 11 panels labelled with room names (The Lobby, Stories, The
      Ninth Bell, Returns Hatch, Arcade, Signal Path, Lamplight, Gallery, Social
      Room, Archive, Creator Studio) plus a title card. An overview board of the
      universe's intended atmospheres.

  README-USAGE.txt
      The pack's own usage notes: what each image is for, the instruction not to
      use a whole collage as a live room background, not to reproduce baked-in
      UI or labels, to produce a new separate text-free image per verified room,
      to keep content and the controller as live HTML/CSS, and a note that image
      generation does not establish third-party media rights.

Summary of classification: 2 interface mockups/boards with baked-in UI (01, 03),
3 multi-panel collage boards (01, 02, 08 - 01 counted once above), 5 single
artworks (04, 05, 06, 07, and no others). No image in this pack is a finished,
text-free background for a single room.

8. CONFLICTS, LIMITATIONS AND OPEN ITEMS
--------------------------------------------------------------------------------

  L1  These are reference boards, not production backgrounds.
      Eight PNGs exist for eleven intended room identities, and the two fullest
      boards each hold 12 panels inside one image. Producing per-room backgrounds
      requires new, separate, text-free artwork. Nothing in this pack can be
      used as-is as a room background, and no such use has been made.

  L2  Baked-in text and UI must not be reproduced.
      Images 01, 02, 03 and 08 contain generated labels, navigation or controls.
      The pack README forbids reproducing them in the product. Any future
      implementation must supply its own real text and its own live controller.

  L3  Media rights and provenance remain unverified.
      The pack carries no creator, source, licence or attribution metadata, and
      its README states that image generation does not by itself establish
      third-party media rights. No asset here should be described as cleared,
      licensed or royalty-free. Before any of this artwork influences published
      imagery, the owner should confirm that the generated images are original
      to this project and record provenance. This is an open restriction carried
      forward, not something this extraction could resolve.

  L4  The intended room list needs mapping to real routes before implementation.
      The README lists eleven room identities. The live project's route set
      includes /film/ (the protected original production), which is not among
      those eleven, so the mapping from identity to route is a decision for the
      next stage. No route was changed here.

  L5  Verification depth.
      Integrity was verified by archive test, per-file stream comparison and
      image decoding. Deeper checks (pixel-level comparison against a second
      source, EXIF/metadata audit, colour-profile analysis) were not performed
      because no independent second copy exists to compare against and the files
      are byte-identical to the archive as supplied.

  L6  No visual judgement is implied.
      Classifying an image as a board, mockup or single artwork is a structural
      observation from inspection. It is not an approval of the artwork's design
      quality, and no accessibility or suitability assessment of the imagery was
      performed.
